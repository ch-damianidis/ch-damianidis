## 🔬 About Me

I am a PhD candidate working on **causal inference methods in meta-analysis**, with a focus on **transportability**, **individual treatment effects**, and **statistical programming**. I care about reproducible research workflows and building tools that make complex methods easier to explore and share.

- 🔭 **Current Focus:** Causal inference in meta-analysis, Transportability and generalizability, Individual treatment effects (ITE).
- 🌱 **Advocating for:** Reproducible research & Research software with a clean web interface.
- 💬 **Ask me about:** Evidence synthesis, R package development, and statistical modeling.

## 🚀 Selected Projects

### 📊 [Living Network Meta-Analysis Tool](https://github.com/ch-damianidis/lsr/tree/main/lsr-main)
An interactive **R Shiny application** for evidence synthesis workflows. 
* **Features:** Supports NMA/CNMA analysis, node merging, diagnostics, and self-contained report export.

### 🌐 [Quarto + WebR / QuartoLive project](https://github.com/ch-damianidis/living-nma-cnma-tool)
A reproducible web-based prototype for a Living NMA workflow.
* **Features:** Built with Quarto documentation, reusable R functions, and interactive browser-side modules powered by `webR`.

> *I like projects that can be shared, explored, and reproduced easily — ideally with a website, clear documentation, and a clean workflow from analysis to presentation.*
