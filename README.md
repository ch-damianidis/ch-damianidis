# Hi, I'm Charis 👋

PhD candidate working on **causal inference methods in meta-analysis**, with a focus on **transportability**, **individual treatment effects**, and **statistical programming**. I care about reproducible research workflows and building tools that make complex methods easier to explore and share.

## What I care about

- Causal inference in meta-analysis
- Transportability and generalizability
- Individual treatment effects
- Statistical programming
- Reproducible research
- Research software with a clean web interface

## Selected projects

- **Living Network Meta-Analysis Tool**  
  An interactive R Shiny application for evidence synthesis workflows, supporting NMA/CNMA analysis, node merging, diagnostics, and self-contained report export.

- **Quarto + WebR / QuartoLive project**  
  A reproducible web-based prototype for a Living NMA workflow, with Quarto documentation, reusable R functions, and interactive browser-side modules powered by webR.

## Why I build this way

I like projects that can be shared, explored, and reproduced easily — ideally with a website, clear documentation, and a clean workflow from analysis to presentation.
